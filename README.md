# devdennie.github.io

Personal portfolio of Dennis Kabaso, CS student at NIPA, founder of D3VCorp.

The site is a static [Vite](https://vite.dev/) app. It is served from the repository root (`base: '/'`).

The frame uses a `#13140F` background, `#FCFDF8` text, a `#F0F850` lime accent, and `#A078F8` violet as a token. Headings are Bricolage Grotesque and text is Instrument Sans. JetBrains Mono is loaded with them. Google Fonts is the only external resource. The header, section slots, and footer are in place; the page copy is still to come.

## Run it locally

```bash
npm ci
npm run dev
```

Open http://localhost:5173/

## Build

```bash
npm run build
npm run preview
```

The preview serves `dist` at http://localhost:4173/
