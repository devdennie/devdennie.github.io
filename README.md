# devdennie.github.io

Personal portfolio of Dennis Kabaso, CS student at NIPA, founder of D3VCorp.

The site is a static [Vite](https://vite.dev/) app. It is served from the repository root (`base: '/'`).

## Run it locally

```bash
npm ci
npm run dev
```

Open http://localhost:5173/

## Build

```bash
npm run build
npm run preview
```

The preview serves `dist` at http://localhost:4173/
