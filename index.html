Projects

Three analysis notebooks, a course chatroom, and two live web demos.

  • Notebook

    Lusaka Food Prices Analysis

    Analyses World Food Programme retail prices for maize, mealie meal and fuel with pandas and matplotlib/seaborn, one question at a time, keeping each comparison in a single unit and price type.

    Repository for Lusaka Food Prices Analysis

  • Course

    Simple Chatroom

    A browser chatroom for an Internet Technology course, built in PHP with PDO and MySQL. Sign-up stores bcrypt password hashes, requests carry CSRF tokens, and the shared room loads messages by polling.

    Repository for Simple Chatroom

  • Demo

    BookIt Lusaka

    A mobile-first booking page in HTML, CSS and JavaScript for Lusaka salons, clinics and barbers. It is a static demo: sample businesses and prices, bookings kept in the browser, and a WhatsApp handoff, with no accounts, server or payment provider.

    Live demo of BookIt Lusaka Repository for BookIt Lusaka

  • Demo

    ZedDrive Motors

    A mobile-first site for a fictional Lusaka dealer, with sale filters, rental date totals and a WhatsApp handoff. ZedDrive Motors is fictional: the cars, prices and contact details are sample data, and the deposit screen takes no payment.

    Live demo of ZedDrive Motors Repository for ZedDrive Motors

  • Notebook

    Lusaka road safety

    Charts published crash totals for Lusaka Province, 2016–2024, with pandas and matplotlib/seaborn: severity, causes, timing, and how Lusaka compares with other provinces. The tables are yearly and quarterly aggregates, not one row per crash.

    Repository for Lusaka road safety

  • Notebook

    Lusaka air quality

    Answers six questions on daily air quality in Lusaka, from 1 August 2022 to 18 February 2026, with pandas, matplotlib and seaborn. The figures are modelled CAMS estimates from Open-Meteo, not ground-monitor readings and not an official health report.

    Repository for Lusaka air quality

About
